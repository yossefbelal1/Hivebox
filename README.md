# \# HiveBox

###### 

#### An end-to-end DevOps \& SRE hands-on project built iteratively following the Dynamic DevOps Roadmap.

#### HiveBox is a RESTful API service for beekeepers that integrates with openSenseMap to fetch and serve environmental sensor data (such as temperature).

######
